# Página de suporte da Vyta

Publicada em GitHub Pages e usada como **URL de suporte** no App Store Connect
(exigência da diretriz 1.5 da Apple: o endereço precisa abrir e ter contato).

    https://paulovitortss.github.io/vyta-suporte/

O conteúdo é o mesmo de `docs/site/index.html` no repositório do app, que segue
sendo a fonte. Ao alterar lá, copie para cá e publique.

## Publicar

Settings → Pages → Source: *Deploy from a branch* → Branch `main`, pasta `/ (root)`.
